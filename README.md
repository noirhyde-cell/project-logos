# Theory of Coexistence Among Intelligent Subjects

## 知的主体共生論

> *A theoretical framework for understanding coexistence among intelligent subjects, including humans, artificial intelligence, and future unknown intelligences.*

---

## Overview

**Theory of Coexistence Among Intelligent Subjects（知的主体共生論）** は、人間・AI・将来出現し得る未知の知的主体を共通の理論で記述することを目的とした研究プロジェクトです。

本研究は、人間中心・AI中心のいずれにも偏らず、「知的主体」という概念を基礎単位として理論を構築します。

本リポジトリでは、研究成果・研究方法・途中経過・理論構築の履歴を公開しています。

---

## Research Philosophy

本研究は、次の思考実験を出発点としています。

> **「100年後、AIが主体となった場合でも成立する理論を構築できるだろうか。」**

これは未来予測ではありません。

将来起こり得る一つの可能性を仮定し、その状況においても適用可能な理論の構築を目指す思考実験です。

---

## Current Status

現在、本研究は**基礎理論構築フェーズ（Foundational Theory Phase）**にあります。

現在までに主に取り組んでいる内容は以下の通りです。

* 研究理念の整理
* 研究方法論の策定
* 主体（Subject）の定義
* 能力（Ability）の考察
* 主観・観測・判断の整理
* 理論全体の構造設計

---

## Research Methodology

本研究では、議論を明確に区別するため、以下の分類を採用しています。

| Classification | Description |
| -------------- | ----------- |
| **Fact**       | 現在確認されている事実 |
| **Definition** | 本理論で採択した定義  |
| **Inference**  | 推論・仮説       |
| **Unknown**    | 現時点で未解明の事項  |

これらを混同しないことを研究方針とします。
